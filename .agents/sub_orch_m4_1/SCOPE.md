# Scope: M4 - UI Inputs & Toggles Implementation

## Architecture
- `src/app/calculator/CalculatorParams.tsx`: General input section containing form controls and toggles.
- `src/SimulationProvider.tsx`: React context provider managing simulation state and worker communication.
- `src/app/calculator/views/*`: Result visualization views (`SummaryView`, `PortfolioValueView`, `AvailableSpendingView`, `SimulationsListView`, `DataAssumptionsView`).

## Key Implementation Requirements
1. **Global Market Data Toggle**: Include a user-facing toggle in the general input section (`CalculatorParams.tsx`) to switch between US market (`us`) and Global market (`global`).
2. **Accumulation Phase & Timeline Calculation Toggle**:
   - Add fields for "Current Age" and "Additional Yearly Contributions".
   - Add a toggle for `Retirement Period Only` vs `Retirement & Accumulation Period`.
   - **Retirement Period Only**: Disables and greys out the Retirement Age, Current Age, and Additional Yearly Contributions fields.
   - **Retirement & Accumulation Period**: Enables those fields and passes them to the simulation config.
3. **Simulation Mode Toggle**:
   - Add a toggle for `Historical Backtesting` vs `Scrambled Monte Carlo`.
   - Ensure `SummaryView`, `PortfolioValueView`, `AvailableSpendingView`, `SimulationsListView` seamlessly render the 1,000 runs generated by the worker.
4. **Data Assumptions View**: Update `DataAssumptionsView.tsx` to use `getAllMarketData(config.marketDataMode)` to reflect the selected market data.
