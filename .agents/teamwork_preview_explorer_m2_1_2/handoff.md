## 2. Logic Chain

1. **Reconciling Interface Contracts & Backwards Compatibility**:
   - *Observation*: `src/workers/simulation.worker.ts` currently calls `getMarketDataForYear(year)` and `getValidStartYears(duration)`. `PROJECT.md` suggests `(mode, year)`, while `SCOPE.md` specifies `(year, mode?: 'us' | 'global')`.
   - *Inference*: Adopting the `SCOPE.md` signature `(year: number, mode: 'us' | 'global' = 'us')` is the correct architectural choice. By placing `mode` as an optional second parameter with a default value of `'us'`, we guarantee 100% backwards compatibility with existing simulation worker calls while enabling future simulation engine expansions (M3) to pass `config.marketDataMode`.

2. **Integrating `globalMarketData`**:
   - *Observation*: `src/lib/globalMarketData.ts` will be generated by the Worker (based on Explorer 1's CSV parsing plan) to export `globalMarketData: Record<number, MarketDataPoint>`.
   - *Inference*: `src/lib/marketData.ts` must import `globalMarketData` from `./globalMarketData`.

3. **Updating `getMarketDataForYear` with Robust Fallbacks**:
   - *Observation*: `getMarketDataForYear` currently checks `shillerMarketData[year]` and returns a static fallback object if out of bounds.
   - *Inference*: When `mode === 'global'`, the function should check `globalMarketData[year]`. If `year` is out of bounds for the global dataset, it must return a robust fallback `MarketDataPoint` tailored for global market baselines (e.g., `startCpi: 322.0, endCpi: 329.0, cape: 25.0, dividendYields: 0.015, stockMarketGrowth: 0.07, bondsGrowth: 0.04`). When `mode === 'us'`, it retains the exact existing `shillerMarketData` lookup and fallback.

4. **Updating `getValidStartYears` for Global Timeline Boundaries**:
   - *Observation*: `getValidStartYears` loops from `1871` to `2025 - duration + 1`. The MSCI World dataset starts in 1970.
   - *Inference*: When `mode === 'global'`, the loop must start at `1970` instead of `1871`. The fallback for extremely long durations (`[1990, 2000, 2010]`) remains perfectly valid for both modes.

5. **Implementing `getAllMarketData`**:
   - *Observation*: `SCOPE.md` requires `getAllMarketData(mode?: 'us' | 'global'): Record<number, MarketDataPoint>`.
   - *Inference*: We must implement and export `getAllMarketData(mode: 'us' | 'global' = 'us'): Record<number, MarketDataPoint>` which simply returns `mode === 'global' ? globalMarketData : shillerMarketData`.
